## Hard rules
- The UI thread NEVER blocks: rustypipe and yt-dlp only on the backend runtime; images only through egui loaders (egui_extras http loader fetches off-thread).
- No unwrap()/expect() on fallible runtime paths.
- Ignore stale events (search results for an old query, pages that arrive after navigating away still go into the cache — that's fine and desirable).
- Don't implement phase 2b (queue side panel, prefetch, MPRIS, persistence) or milestone 3 (auth, library contents, liked music, sidebar playlists).
- Never call rustypipe player/stream APIs.
