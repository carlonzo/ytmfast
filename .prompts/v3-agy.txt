## Scope (PLAN-v3 items 2, 7, 3, 6, 8)
1. Palette + themes (prerequisite for 2 and 3). Replace the COLOR_* constants with a `Palette` struct (bg, surface, surface_hover, divider, text, text_secondary, accent) held in egui context data or passed via App, with built-in Dark (today's colours, the default) and Light. Every draw function reads the palette; `apply_theme` builds egui Visuals from it. Keep the cover-tinted player bar / mini player (`eased_tint`) working on top of the palette.
2. Follow Omarchy's theme (spotifast src/app.rs custom themes / `follows_omarchy`). Omarchy keeps the current theme in `~/.config/omarchy/current/theme/` (look for its colour files, e.g. the alacritty/kitty/waybar/hyprland ones; read spotifast for which file it parses). Map background/foreground/accent onto the Palette. Watch for changes (poll mtime every 2 s on a background thread, or `notify` if already in the tree) and switch live. Settings: `theme: Theme { Dark, Light, System, Omarchy }`, default `System`, which picks Omarchy when its theme dir exists, otherwise the desktop preference (item 7). Theme picker in the Settings dialog.
3. Light/dark following the desktop (spotifast src/appearance.rs): read `org.freedesktop.appearance color-scheme` from the XDG desktop portal over D-Bus (zbus is already in Cargo.lock via accesskit/ksni; a blocking zbus call on its own thread) and follow its change signal. macOS: use what winit/egui report (`ctx.system_theme()`). No slow bus may delay the first frame.
4. Blurred cover backdrop behind the lyrics panel (spotifast src/images.rs `LYRICS_BLUR`, softened covers). Decode the current cover (images::shared() bytes, use `images::sized(url, 544)`), downscale to ~64 px and box/gaussian blur it OFF the UI thread, upload once per track as a texture, draw it stretched behind the lyrics with a dark scrim so text contrast stays >= 4.5:1, and crossfade (0.4 s) when the track changes. Also offer it in the mini player tall layout behind the cover (setting `mini_backdrop: bool`, default true).
5. Keyboard shortcuts (spotifast src/ui/keys.rs). Ctrl on Linux / Cmd on macOS: Ctrl+Left/Right previous/next track, Ctrl+Up/Down volume +-5%, Shift+Left/Right seek -+10 s, Ctrl+L or `/` focus search, Ctrl+Q quit (real quit, not background), Ctrl+, settings, Escape closes dialogs/menus. Never fire while a text field has focus (except Escape). Keep Space and Ctrl+M. Update the README Shortcuts table.
6. Colour emoji (spotifast src/emoji.rs via `fastframe-emoji` from the same fastframe git tag v0.4.1 the project already uses). Titles with emoji render in colour; without a colour emoji font fall back silently. ONE attempt rule: if fastframe-emoji needs spotifast's forked egui and won't build against egui 0.36 after one honest attempt, drop it and note that in the commit message.
