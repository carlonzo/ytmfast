## Scope (PLAN-v3 items 1, 9, 4, 5)
1. Spectrum visualiser in the player bar (spotifast src/vis.rs + src/ui/player_bar.rs `spectrum`).
   - Audio tap: a rodio `Source` wrapper in a new src/vis.rs around the decoder in `Player::play_file`, copying mono-mixed samples into a shared ring buffer (`Arc<Mutex<VecDeque<f32>>>`, ~0.5 s). It must cost nothing noticeable on the audio thread (no allocation per sample, short lock, or a lock-free ring).
   - Analyser on the UI thread: 512-sample window with a little lag (spotifast `LAG`), Hann window, FFT (a small radix-2 FFT written here, or `rustfft` if you prefer a crate), ~24 log-spaced bands, Winamp-style falloff and peak caps (spotifast constants), stepped at a fixed 60 Hz regardless of frame rate.
   - Drawing: bars rising from the bottom edge of the player bar, behind the controls, swept between two colours derived from the cover accent (`images::shared().accent`, fallback COLOR_ACCENT_RED), with peak caps; low alpha so text stays readable. Repaint at ~30 fps only while playing and the window is visible; nothing while paused.
   - Settings: `visualiser: bool` (default true) with a checkbox in the Settings dialog.
2. Ten-band equalizer + limiter (spotifast src/eq.rs, src/limiter.rs) as rodio `Source` stages in the same chain (decoder -> EQ -> limiter -> tap). Bands 31 Hz..16 kHz, -12..+12 dB, preamp; settings `eq_enabled: bool` (default false), `eq_gains: [f32; 10]`, `eq_preamp: f32`, applied live without restarting the track (shared state read per block, filters rebuilt only on change). UI: an "Equalizer" section in the Settings dialog with 10 vertical sliders + preamp + Reset + a few presets (Flat, Bass boost, Treble boost, Vocal). EQ disabled must be bit-exact passthrough.
3. Local play history (spotifast src/history.rs): a track counts after 30 s or half its length of actual listening (not skips). Store in `~/.local/share/ytmfast/history.json` (newest first, capped at 500, written off the UI thread). Show a "Recently played" shelf at the top of Home (most recent distinct tracks, up to 20) using the existing track-card/shelf drawing; click plays from that track in that list.
4. Command-line control over the existing single-instance socket (src/tray.rs, spotifast src/single_instance.rs): `ytmfast play-pause | play | pause | next | previous | show | quit | now-playing`. The running instance answers one line per request (`ok`, or for now-playing a JSON object `{title, artist, album, playing, position_secs, duration_secs}` from a snapshot the UI updates each tick, never touching App from the listener thread). Unknown verbs reply `error: unknown command`. With no running instance: `show` starts the app as today, other verbs print "ytmfast is not running" and exit 1. Plain `ytmfast` keeps today's behaviour. Add a README section with Waybar `custom/ytmfast` and Hyprland bind examples.

## Hard rules
- UI thread never blocks on IO/network. Audio thread never allocates per sample or holds a lock for long.
- No unwrap()/expect() on fallible runtime paths.
- Don't break: background mode (window closed, App ticking in main's loop), mini player, MPRIS, prefetch, cache limits, existing tests.
- macOS must still compile: keep Linux-only code behind cfg(target_os = "linux"); the CLI socket may be unix-wide (cfg(unix)).

## Tests (unit, no network)
- FFT/analyser: a pure sine lands in the expected band; silence gives zero bars; falloff steps are frame-rate independent.
- EQ: disabled = identical samples; +6 dB at a band boosts a sine at that frequency by ~2x amplitude; limiter keeps output <= -1 dBFS for a +12 dB boosted full-scale sine.
- History: counting threshold, skip not counted, cap at 500, distinct ordering for the shelf, JSON round trip.
- CLI: verb parsing, reply formatting, now-playing JSON from a snapshot.
- Settings round trip with the new fields; `{}` still deserializes to defaults.
